### M4　斜率法定总提前量（2 档 × 3~5 发）

```bash
cd ~/fp_aim
~/run_measure.sh slope M4_$(date +%m%d) 0.057 0.243
```

**为什么是 0.057 / 0.243**：两档张开 186 ms，落点差 ≈150 mm（0.8 m/s × 0.186 s），肉眼读得出；第二档若停在旧的 0.17 一级（只比真值高十几毫秒），新口径下残余只剩 ~14 mm，读不出来。


**每档打 3~5 发**，量落点沿**靶子转动方向**的偏移（mm，**超前为正**、落后为负）。
**填模板**（车机；脚本已生成 `logs/slope_M4_*.txt`）：


## 4. 测量的先后顺序为什么是这样

```
M1 零位 ──► M2 errY/延迟/几何 ──► M3 符号 ──► M4 总提前量 T ──► M5 门限
                     │                    │            │
                     │                    │            └─► M6 基线 ─► M7 低位 ─► M8 arrival ─► M8.5 相位 ─► M9 人工门
                     └─►（B1/B2 提供 M4 的拆分）
```

| 顺序约束 | 原因 | 违反了会怎样 |
|---|---|---|
| **M1 必须最先** | 零位偏置与 lead 误差在"落点"上完全等价；errY 里也含 yaw 零位 | M4 算出的 `DSH_LEAD` 会把零位误差吸收 ⇒ 以后改零位，lead 就错了 |
| **M2 在 M1 之后** | errY 含零位 | 门限按"带零位的 errY"定 ⇒ 偏大 |
| **M2 必须在转靶上做** | 静止靶没有跟踪滞后 | 测不出 B1/B2，门限没依据 |
| **M3 在 M4 之前** | 符号错 ⇒ 斜率外插出垃圾 | lead 越修越糟，还可能误删 `+ M_PI` |
| **M4 两场转速/距离一致** | k = r·ω 与转速成正比 | 算出的 T 无效 |
| **M6 在 M1/M3/M4/M5 之后** | 基线要建立在"零位对、lead 对、门限对"之上 | 对照组本身有偏 ⇒ 后面每场都比错 |
| **M7/M8 在 M6 之后、一次只改一个** | 要能归因 | 分不清是谁带来的变化 |
| **延迟类测量绝不能开录像** | 写盘抖动污染 `send_ns` | B1/B2 偏大 ⇒ lead 标错 |

### 4.1 一场里能同时测的几个数（省时间）

| 场 | 一次拿到 |
|---|---|
| **M2** | A2 errY、B1、B2、C1、C2、C3、D1（**7 个数**） |
| **M4** | T（总提前量）+ B3（给了 B1/B2 才有）+ k 比值（校验 ω 与读数） |
| **M6/M7/M8** | 命中/发数 + 弹频 + blocked 分解（汇总里自动算）；**M8.5** 顺带看 `t_arr` 与 `dist` 是否自洽 |

### 4.2 每场的最小样本量

| 测什么 | 最少 | 够用 |
|---|---|---|
| errY / 延迟 / 选板频率 | 10 s | **30 s** |
| 零位 | 3 发 | 5 发（看散布） |
| 斜率法落点 | 3 发 | 5 发（能看散布更好） |
| 命中率 | 3 发 | **10 发**（每挡上限） |

## 7. 常见坑

| 坑 | 现象 | 防 |
|---|---|---|
| **车机永远没外网** | `pip install` / `apt` 全挂 | 分析全在笔记本；车机只编译、跑、记数 |
| **笔记本 ping 不到车机** | 防火墙挡**入站** ICMP | 从车机 ping 笔记本才准（`~/run_measure.sh link`）；或直接试 scp |
| **`ssh 192.168.1.199` 超时** | 以为网络/密钥坏了 | 就是车机没开机或没连网线；**别反复试**，现场直连后再验 |
| **cmd 里 `cd D:\...` 不换盘符** | 提示符还在 `C:\`，后面相对路径全错 | `cd /d D:\MTG\Documents\OC\fp_aim_fkey`，或先敲 `D:` |
| **cmd 里跑 PowerShell 语法** | `$t` / `Get-ChildItem` 直接报错 | 标着 powershell 的块要在 PowerShell 里跑；cmd 里就写死文件名，别用通配符 |
| 参数没重启就改 | "我明明 export 了" | `DSH_LEAD`/`DSH_FIRE_DELAY`/`DSH_STATIC_*` 是 `static` ⇒ 必须重启；看启动行"预测时域"自证 |
| `DSH_LOW_PLATE` 写错静默回落 | 想跑 always 跑成 warmup | 启动行打**原字符串 + 解析结果**；三态只认 `0/1/2` |
| 开录像 | 58→45 fps，时间基准全乱 | `record_dir: ""`；延迟测量期间尤其不能开 |
| **用固定靶标 lead** | 怎么调都不变 | 固定靶视在角速度 = 0 ⇒ lead 恒为 0；必须在转靶上标 |
| **M1 没做就 M4** | lead 把零位误差吸收 | 严格按 §4 顺序 |
| 落点偏移读不出 | 8 mm 肉眼读不准 | 加大 Δlead（0.057→0.243 ⇒ 移动 150 mm）；或用带网格的纸 |
| `cmd yaw` 样本太少 | M3 没结论 | 靶子转起来、跑满 10 s |
| 每挡超发 | 程序不限发（`max_rounds_per_stage: 0`） | 正式提交开 `DSH_FIRE_KEY_ENABLE=1`，人自己数 ≤10 |
| 车机上没有 .git | `git checkout` 报 not a repository | 回退用 `cp src/task_2.cpp.bak_aim src/task_2.cpp` |
| `grep -c` 返回 1 | `&&` 后面的命令不执行 | 用 `;` 或分行 |
| PowerShell 不展开通配符 | `py tools\parse_session.py logs\*.log` 说找不到 | 先 `$l = (Get-ChildItem logs\*.log).FullName` 再传 |
| yaml 里有两个 `fire_interval_s` | 看错行以为 0.0834 | **第 70 行是 task2（0.2）**，第 89 行是 task3 |
| 日志 GBK 乱码 | Windows 直接打开是乱码 | 用 VS Code 选 GBK，或先转码；别用记事本判断内容 |
| 包解压不完整 | grep 计数少、编译缺符号 | `install.sh` 的 `sha256sum -c` 必须全过 |
| **增量包铺在旧树上（混版）** | 编译过了但行为不对 / 找不到新符号 | 用完整包时先 `mv` 走旧树再解压（§1.3 A）；增量包只在车机已是同版本树时用 |
