## 1. task3 的规则（和 task2 完全两套，照搬必错）

| 项 | task2（装甲板） | **task3（前哨站）** |
|---|---|---|
| 目标 | 4 块装甲板 | **只有 outpost 这一个目标**（3 块板，r = 0.2765 m） |
| 选板 | 按 facing/到达角选 | 固定取顶板；开 `DSH_T3_ARRIVE_DEG` 后按弹着朝向重选（§4.2） |
| 开火节奏 | `fire_interval_s` 0.2 | **0.0834 s（12 Hz）** |
| 发数上限 | `max_rounds_per_stage` | `max_rounds_per_stage`（standard 是 0 = 不限） |
| 提前量 | `DSH_LEAD` 两档（低 0 / 中高 0.024） | **`DSH_LEAD` 单值，默认 0** |
| pitch 偏置 | `pitch_offset` 0.5 | 读同一个键（步兵 0.5） |
| 关键阈值 | `zoom_thres`、`speed_band_split` | **`outpost_z_window` 0.30、`outpost_top_margin` 0.12** |

前哨站几何：ω ≈ 2.5 rad/s，r = 0.2765 m ⇒ 切向 0.69 m/s；3 m 处视在角速度 ≈ 12.6 °/s。
板宽 129 mm 在 3 m 处张角 2.46°，**半宽 1.23°**。缺 57 ms 补 = 0.72°，约半个板半宽。

## 4. 提前量怎么定（唯一需要判断的地方）

```bash
DSH_LEAD=0 ./build/task_3 configs/standard.yaml
```

- **先打 lead=0**：2.5 rad/s、3 m 处只差 0.72°，接近一个板半宽。
- 落点在转动的**前方**（打早）⇒ 加 lead，步长 0.02。
- 落点在**后方** ⇒ 先查 `f` ≥ 55、`w` 是否稳，而不是继续加 lead。
- **lead 只影响瞄点，不影响开火时机**（门控里没有 lead 项）。

**换算（3 m，2.5 rad/s）**：1 cm ≈ 8.7 ms；1 板宽（129 mm）≈ 112 ms。
⚠ 别套 task2 的 0.024（那是 5.6 rad/s + 另一颗镜头标出来的）。

### 4.2 别打「正在转走」的板：到达角门控 `DSH_T3_ARRIVE_DEG`

**现象**：弹着总在板转走的那一侧、命中面是斜的。病因是**时机**，不是选板写错。

3 块板相隔 120°、ω≈2.5 rad/s（143°/s），开火到弹着 0.15–0.30 s ⇒ 板转过 **20–42°**。
"现在正对"的那块到弹着时必然转走；该打的是**再过 t_arrive 才转正**的那块。

```bash
# 只在「弹着瞬间 |朝向| ≤ 12°」时开火，并自动在 3 块板里挑最正的那块
DSH_T3_ARRIVE_DEG=12 ./build/task_3 configs/standard.yaml
```

- 缺省 `0` = 关闭，行为与旧版完全一致。
- 12° 约 **2 Hz**（每 0.84 s 一个窗口，窗口内 2 发）；20° 更宽容约 3–4 Hz；8° 更严。
- HUD 多出 `arr {弹着朝向}deg(gate 12)`，越接近 0 越好。
- 若它朝目标**背后**那块瞄（可能被结构挡），把门限收到 8° 或先关。

## 4.5 打满 12 Hz：开火放宽开关 `DSH_FIRE_RELAX`

默认全关（严格门控，实测约 7–9 Hz）。

```bash
DSH_FIRE_RELAX=1 DSH_LEAD=0 ./build/task_3 configs/standard.yaml   # 只补丢帧（先这个）
DSH_FIRE_RELAX=2 DSH_LEAD=0 ./build/task_3 configs/standard.yaml   # 再跳预热与 NIS
```

两档都保留：必须有目标 / 未发散 / 测距 ≤ 300 ms。1 档 HUD 显示 `HOLD`，2 档不显示。
判据：1 档能到 11–12 Hz 且不发散就用 1 档；仍 < 10 Hz 再上 2 档。

## 5. 开火条件（不发射时按这张表查）

| 门 | 代码 | 怎么看出来 |
|---|---|---|
| 有检测 | `has_detection` 且 `target_alive(target_hold_ms)` | HUD 没目标 / 框闪 |
| 稳定 | `is_converged() && frames_since_init >= 15` | 前 15 帧不开火 |
| NIS | `nis_failure_rate < 0.3` | 日志 `[warn] nis` |
| 间隔 | `since_last >= 0.0834 s` | 12 Hz |
| 发数 | `rounds < max_rounds`（0 = 不限） | HUD `rounds` |
| 模式 | `require_auto_aim_mode ? AUTO_AIM : 1` | 裁判系统没进自瞄 |
| 到达角 | `|facing_arrive| <= DSH_T3_ARRIVE_DEG`（默认关） | HUD `arr …(gate …)` |
| HOLD | 跟踪丢 > 300 ms | HUD `HOLD` |
| 人工门 | `F=OFF(auto)` 表示不挡；`F=SAFE` 才挡 | HUD `F=…` |

`HOLD` 时**不会开火**，防"对着冻结角度空打"。`lowgate=OFF` 是写死的，task3 没有低位靶规则。

## 6. 正式跑（按计时开始）

```bash
cd ~/fp_aim
env -u DSH_FIRE_DELAY -u DSH_FIRE_KEY_ENABLE -u DSH_LOW_PLATE -u DSH_AIM_SELECT \
  DSH_LEAD=0 ./build/task_3 configs/standard.yaml 2>&1 | tee logs/T3_$(date +%m%d_%H%M).log
```

- `env -u` 清掉 task2 留下的变量（`DSH_AIM_SELECT` 对 task3 无效，但别留着误导）。
- 前 0.3 s 是建滤波器，头几发不开火正常。
- 盯三样：`rounds` 涨不涨、`w` 稳不稳（≈2.5）、落点在哪。
- 退出：窗口按 `q` 或 `Ctrl+C`（会补发停转指令）。

## 8. 六个坑（每个都真实踩过）

1. **跑错 yaml**：步兵用 sentry → 画面倒 180°，必空。判据是画面朝向（task_3 不打配置行）。
2. **rotation / pitch 只改一个**：`0/0.5` 与 `180/0.0` 是两套，单改一个必偏。
3. **把 task2 的 `DSH_AIM_SELECT=arrival` / `DSH_LOW_PLATE=2` 带过来** → task3 无此机制，说明环境没清干净。
4. **在 `~/fp_aim` 里解包** → 变成 `~/fp_aim/fp_aim/`，要在 `~` 解开。
5. **正式跑时第一次试 lead / 试门控** → 拿唯一机会做实验，先在试打轮定。
6. **没开 PlotJuggler 就找曲线** → plotter 是 UDP 广播，没监听静默失败，不影响开火。
